How to log a run

Email Ryan McCracken with "Run challenge" in the subject line and the distance in km in the body. If the run was on a different day to the email, say which day. One run per line if you are sending a few at once.

Emails are picked up at 7am and 5pm each day and the board updates itself a few minutes later. Only runs from 5 October to 2 November count.
